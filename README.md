# Tarun Kumar — Creative Technologist & Developer Portfolio

A motion-driven, editorial portfolio website showcasing intelligent AI clinical architectures, real-time IoT hardware telemetry, computer vision gesture systems, and high-performance algorithms.

Built with the **Motion.ai** design language, featuring dual-layer canvas spotlight masks, kinetic typography marquees, cursor-following project previews, and an interactive developer HUD terminal.

## 🚀 Local Development

Open `index.html` directly in your browser, or run:

```bash
# Using Node.js
node server.js

# Or using Python
python -m http.server 3000
```

Visit `http://localhost:3000` to preview.
